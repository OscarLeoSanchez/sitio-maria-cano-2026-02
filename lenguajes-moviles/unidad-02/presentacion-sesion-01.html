Qué es Git

Git guarda fotos del proyecto en una cadena

Git es un sistema de control de versiones que guarda la historia del proyecto como una cadena de commits dentro de la carpeta .git, en tu propio equipo.

Ramas

Una rama es un puntero que se mueve

git branchLista las ramas y marca la actual
git switch -c lista-productosCrea la rama y se mueve a ella
git commit -m "mensaje"Avanza solo la rama actual
git switch mainVuelve a la rama principal
git merge lista-productosTrae a main los cambios de la rama

Repositorios remotos

Git guarda, GitHub aloja

Git

  • Herramienta que se instala en tu equipo
  • Guarda el historial en tu carpeta, sin internet
  • Se maneja con comandos: add, commit, switch
vs

GitHub

  • Servicio en internet que aloja repositorios
  • Agrega pull requests y revisión de código
  • Requiere una cuenta
Git funciona sin GitHub. GitHub aloja en la nube los repositorios de Git.

2

Abre el archivo, deja la línea que quieres y borra las tres líneas de marcadores.

git commit cierra la fusión. Para cancelarla usa git merge --abort.

Errores frecuentes

Los errores que más se repiten

flutter no se reconoce

La terminal no encuentra el SDK

CorrecciónAgrega la carpeta bin del SDK al PATH y abre una terminal nueva.

git push rechazado

El remoto tiene commits que no tienes

CorrecciónGit responde rejected (fetch first). Haz git pull y vuelve a git push.

Borrar sin revisar antes

En la terminal no hay papelera

CorrecciónMira el contenido con ls antes de usar rm -r o Remove-Item -Recurse.

Marcadores de conflicto en el código

El archivo deja de compilar

CorrecciónBusca <<<<<<< antes de git add y deja solo la versión final.

git commit sin git add

No hay nada preparado

CorrecciónGit responde no changes added to commit. Prepara los archivos con git add.

git commit pide tu identidad

Git no sabe quién eres

CorrecciónGit responde Author identity unknown. Configura user.name y user.email una vez con git config --global.
