Errores en el código

try y catch atrapan lo que falla

Future<void> pedir(Uri url) async {
  try {
    final respuesta = await http.get(url);
    if (respuesta.statusCode != 200) {
      throw Exception('Código ${respuesta.statusCode}');
    }
    debugPrint('Datos recibidos');
  } catch (e) {
    debugPrint('Falló la petición: $e');
  }
}

El servidor responde 404. ¿Qué hace http.get?

La petición sí llegó, así que http entrega una respuesta normal. Solo lanza excepción cuando no hay respuesta: sin red, servidor inexistente o tiempo agotado.

Datos

De texto JSON a un objeto Dart

class Producto {
  final int id;
  final String nombre;
  final int precio;
  final bool disponible;
  Producto({
    required this.id,
    required this.nombre,
    required this.precio,
    required this.disponible,
  });
  factory Producto.fromJson(Map<String, dynamic> json) {
    return Producto(
      id: json['id'],
      nombre: json['nombre'],
      precio: json['precio'],
      disponible: json['disponible'] ?? true,
    );
  }
}
Si el JSON no trae precio, fromJson falla con type 'Null' is not a subtype of type 'int'.

Consumo de servicios

Espera con async y await y muestra tres estados

Future<Clima> obtenerClima() async {
  final url = Uri.parse(
    'https://api.open-meteo.com/v1/forecast'
    '?latitude=6.17&longitude=-75.58'
    '&current=temperature_2m,precipitation',
  );
  final respuesta = await http.get(url);
  if (respuesta.statusCode != 200) {
    throw Exception('Código ${respuesta.statusCode}');
  }
  return Clima.fromJson(jsonDecode(respuesta.body));
}
enum Estado { cargando, listo, error }

Future<void> cargar() async {
  try {
    final datos = await obtenerClima();
    if (!mounted) return;
    setState(() {
      clima = datos;
      estado = Estado.listo;
    });
  } catch (e) {
    if (!mounted) return;
    setState(() => estado = Estado.error);
  }
}

Errores frecuentes

RenderFlex overflowedUn Row con hijos más anchos que la pantalla
Envuelve el widget que puede crecer, casi siempre un Text, en Expanded.
Vertical viewport was given unbounded heightUn ListView dentro de un Column
Envuelve el ListView en Expanded o dale una altura con SizedBox.
La pantalla no cambia aunque la variable síFalta setState
Cambia el valor dentro de setState(() { ... }).
Hot Reload no muestra el cambioCambiaste main() o initState()
Usa Hot Restart: Hot Reload no vuelve a ejecutar esos métodos.
