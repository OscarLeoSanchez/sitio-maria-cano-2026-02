1 De qué trata esta unidad

La Unidad 3 dejó un modelo relacional y una primera mirada a SQL estándar. Esta unidad lo hace funcionar sobre un motor real: MySQL 8.4. El recorrido va en un solo caso, el sistema de ventas con categorías, productos, clientes, empleados, pedidos y detalle de pedido. Primero se prepara el entorno y se crea la base de datos, después se crean las tablas con IF NOT EXISTS, se llenan y se modifican, y por último se consulta, empezando por lo más sencillo y subiendo de nivel.

Cada tema tiene dos materiales que se complementan. La presentación interactiva parte de cero y trae un diagrama antes de cada sentencia, preguntas de predicción antes de los resultados, fallas provocadas a propósito para leer los errores reales de MySQL, y ejercicios con solución que se abre con un clic. La guía es la versión escrita del tema, con la explicación completa, ejemplos con su salida real y ejercicios resueltos, para leer con calma después de la clase. Todas las sentencias y salidas se ejecutaron antes en MySQL 8.4.11. El resultado en tu equipo puede variar según la instalación.

Esta primera parte de la unidad cubre desde el entorno hasta las consultas de una sola tabla. Las presentaciones sobre resumir y combinar datos (funciones de agregación, GROUP BY, HAVING y JOIN), consultas avanzadas (subconsultas, operadores de conjuntos y vistas) y transacciones se agregarán a esta misma unidad.

3 Los archivos del caso de ventas

Los tres archivos reproducen el caso en tu propia instalación. Se ejecutan en este orden, y reiniciar.sql deja la base como al principio cuando quieras repetir un ejercicio.

  • esquema.sql: crea la base ventas y sus seis tablas. Se puede ejecutar más de una vez sin error.
  • datos.sql: carga las categorías, los productos, los clientes, los empleados, los pedidos y su detalle.
  • reiniciar.sql: borra las tablas en el orden que permiten las claves foráneas.

Esta asignatura no tiene calendario ni distribución evaluativa acordada con el docente todavía. Desde esta unidad el motor del curso es MySQL 8.4, y la Unidad 3 usó SQL estándar de referencia.
