Preámbulo

Cuatro términos que vas a ver una y otra vez, explicados una sola vez antes de usarlos.

Qué es la notación O

La notación O describe cómo crece el trabajo de un algoritmo a medida que crece la cantidad de datos, sin depender de qué tan rápida sea la máquina donde corre.

Para qué sirve

Compara dos soluciones de forma justa, mirando cómo escalan, no cuántos milisegundos tardaron hoy en un computador concreto.

Cómo se lee

O(algo) responde una pregunta: si n (la cantidad de datos) se duplica, ¿el trabajo se queda igual, se duplica también, o crece mucho más rápido?

Las tres complejidades de hoy

Notación Qué significa Ejemplo de esta unidad
O(1), constante El trabajo no cambia sin importar cuántos datos haya Leer a[5]
O(n), lineal El trabajo crece en proporción directa a la cantidad de datos Recorrer un arreglo completo
O(n al cuadrado), cuadrática El trabajo crece con el cuadrado de los datos Un ciclo con otro ciclo adentro

Con 10 elementos: O(1) es 1 operación, O(n) son 10, O(n al cuadrado) son 100. Con 1000 elementos: O(1) sigue siendo 1, O(n) son 1000, O(n al cuadrado) es un millón.

Cómo se ven estas curvas al crecer los datos

Esta unidad solo usa O(1) (constante, tan plana que ni siquiera se dibuja aquí), O(n) y O(n al cuadrado), la línea n y la línea n al cuadrado del gráfico. Log n y n log n pertenecen a algoritmos que verás más adelante en la carrera.

Qué es una excepción

Una excepción es la señal que un programa lanza en tiempo de ejecución cuando algo sale mal, en vez de seguir con un resultado incorrecto o fallar en silencio.

Java y Python tienen su propio mecanismo, con nombres distintos para representar el mismo tipo de problema. Verás cuatro de ellas hoy.

Las excepciones de esta unidad

Excepción Lenguaje Cuándo aparece
ArrayIndexOutOfBoundsException Java Acceder a un índice fuera del rango del arreglo
IndexError Python Acceder a una posición fuera del rango de la lista
NullPointerException Java Usar una referencia que todavía no apunta a ningún objeto
IllegalStateException Java Pedir una operación que el objeto no puede cumplir ahora, como desapilar una pila vacía

Dos nombres que vas a escuchar mucho

CPython

La implementación de referencia de Python, escrita en el lenguaje C. Es la que instalas cuando bajas Python desde python.org, y la que casi todo el mundo llama simplemente Python.

OpenJDK

La implementación libre y de código abierto de la plataforma Java. La mayoría de los JDK modernos, incluido el de Oracle, se basan en él.

Cuando esta unidad diga cómo crece una lista de Python o un ArrayList de Java, en realidad está describiendo una decisión de CPython o de OpenJDK, no una regla del lenguaje en sí.

Bloque 1. Vectores o arreglos

Bloque 1

Memoria contigua, acceso directo y el costo real de insertar o eliminar.

Qué es un arreglo

Un arreglo es un bloque de memoria contiguo que guarda un número fijo de elementos del mismo tipo, cada uno accesible por un número de posición llamado índice, que empieza en 0.

Analogía: un casillero de correo con compartimentos numerados en fila. Si sabes el número, llegas directo sin abrir los demás.

Memoria contigua y la ecuación de acceso

Los tres términos de la ecuación

base

La dirección de memoria donde empieza el arreglo completo, la casilla de índice 0.

índice

La posición que se pide, contando siempre desde 0.

tamaño_elemento

Cuántos bytes ocupa cada dato del tipo declarado, siempre el mismo en todo el arreglo.

Por eso el acceso es O(1): la fórmula usa solo una multiplicación y una suma, sin importar si el arreglo tiene 5 elementos o 5 millones.

Cuánto pesa tamaño_elemento, según el tipo

En Java, cada tipo primitivo tiene un tamaño fijo, definido en la especificación del lenguaje (JLS 4.2). Ese número es exactamente el tamaño_elemento de la ecuación anterior.

Tipo (Java) Bytes por elemento
byte 1
char 2
int 4
long 8
double 8

Un int[1000] pesa aproximadamente 1000 * 4 = 4000 bytes, más una pequeña cabecera fija del objeto arreglo. El peso total crece de forma lineal con la cantidad de elementos.

Un arreglo de objetos no guarda los datos adentro

El tamaño de un arreglo de referencias no depende de qué tan largo sea cada objeto al que apunta: todas las casillas miden lo mismo, sea una sola letra o un párrafo completo.

Python: hasta un entero es un objeto

import sys
print(sys.getsizeof(42))            # 28
print(sys.getsizeof([1, 2, 3]))     # 88

En Python no hay tipos primitivos dentro de una lista: hasta el número 42 es un objeto completo de 28 bytes, con su propia cabecera. La lista de 3 elementos solo guarda 3 referencias; los objetos enteros viven aparte, igual que los String en el ejemplo de Java.

Declarar un arreglo

Java

int[] numeros = new int[5];
// JLS 4.12.5: se llena con ceros

Python

numeros = [10, 20, 30]

Java reserva el tamaño desde el inicio y lo rellena con el valor por defecto del tipo. Python crea la lista ya con sus valores.

Qué pasa fuera de los límites

int[] numeros = {10, 20, 30};
System.out.println(numeros[5]);
// ArrayIndexOutOfBoundsException
numeros = [10, 20, 30]
print(numeros[5])
# IndexError: list index out of range

Ninguno de los dos falla en silencio: ambos avisan de inmediato con una de las excepciones de la tabla del preámbulo.

Recorrer un arreglo

Ciclo indexado

Repite mientras un contador i va de 0 hasta el tamaño; en cada vuelta accede a a[i].

Ciclo por cada elemento

Entrega directamente cada valor, uno por uno, sin exponer el índice.

for (int i = 0; i < numeros.length; i++) {
    System.out.println(numeros[i]);
}
for (int n : numeros) {
    System.out.println(n);
}
for i in range(len(numeros)):
    print(numeros[i])
for n in numeros:
    print(n)

O(1) acceder a una casilla

O(n) recorrer el arreglo completo

Insertar en el medio, paso a paso

numeros = [10, 20, 30, 40]
numeros.insert(2, 25)

Insertar o eliminar en el inicio o en el medio cuesta O(n) porque cada elemento desde el punto de inserción hasta el final se mueve una posición.

Eliminar del medio, paso a paso

numeros = [10, 20, 30, 40]
numeros.pop(1)  # quita y devuelve el 20

pop(indice) quita el elemento de esa posición y devuelve su valor. Sin argumento, quita el último.

Complejidad de un arreglo, operación por operación

Operación Complejidad Por qué
Acceder o leer a[i] O(1) multiplicación y suma
Modificar a[i] = x O(1) misma dirección de siempre
Insertar o eliminar al final O(1) amortizado sin desplazamiento, si hay espacio
Insertar o eliminar al inicio o en medio O(n) desplaza todo lo posterior
Buscar por valor O(n) recorrido casilla por casilla

Los arreglos de Java no crecen

En Java, un arreglo tiene tamaño fijo desde que se crea. No existe una operación para agregarle una casilla más: crecer significa crear un arreglo distinto y copiar.

int[] original = {10, 20, 30};
int[] masGrande = Arrays.copyOf(original, 6);
// masGrande = [10, 20, 30, 0, 0, 0]

Crecer significa crear uno nuevo y copiar, un costo O(n) cada vez que se agota el espacio.

Capacidad y tamaño: dos ideas distintas

tamaño

Cuántos elementos hay usados de verdad. Es lo que devuelve len() en Python.

capacidad

Cuánto espacio hay reservado en memoria, usado o no. No es visible directamente, pero existe por debajo.

Cuando una estructura dinámica se queda sin capacidad, no reserva una casilla más: reserva de golpe un bloque más grande, para no repetir esa operación costosa demasiado seguido.

Las listas de Python son arreglos dinámicos por debajo

La documentación de CPython lo describe así: son arreglos de longitud variable, no listas enlazadas. Por debajo hay un bloque contiguo con espacio de sobra.

Qué hace append()

append(valor) agrega valor justo después del último elemento usado, sin desplazar nada. Si sobra capacidad, cuesta O(1).

lista = []
for i in range(20):
    lista.append(i)
    print(id(lista))
# el id() no cambia: el buffer interno se reemplaza por dentro

Capacidad reservada al crecer una lista

Fuente de la secuencia real: el código de listobject.c de CPython. La proporción de crecimiento tiende a 1,125 veces el tamaño anterior, no al doble.

ArrayList de OpenJDK crece cerca de 1,5 veces, pero eso no es parte del contrato público del Javadoc: solo promete O(1) amortizado, el factor exacto es un detalle de implementación.

Caso de estudio: la cola de tareas que parecía rápida

pop(0) quita y devuelve el primer elemento de la lista, desplazando todo lo demás una posición hacia el inicio.

tareas = []
tareas.append(nueva_tarea)      # O(1) amortizado, nada se mueve
siguiente = tareas.pop(0)       # O(n), todo se recorre y se desplaza

Repetir pop(0) en un ciclo cuesta O(n al cuadrado) en total, aunque cada línea se vea inocente. La documentación de collections.deque advierte justo contra usar una lista como cola por esta razón.

Bloque 2. Matrices

Bloque 2

La fila se convierte en cuadrícula: la misma aritmética, un índice más.

Qué es una matriz

Una matriz es una tabla de datos organizada en filas y columnas, donde cada posición se ubica con dos índices en vez de uno solo.

Se puede pensar como un arreglo cuyos elementos son, a su vez, arreglos: cada fila es una lista de valores, y la matriz es la lista de esas filas.

Indexar en dos dimensiones

El primer índice elige la fila, el segundo la columna dentro de esa fila. Sigue siendo O(1): dos cálculos aritméticos en vez de uno, no una búsqueda.

Dos formas de recorrer

Recorrer por filas visita todas las columnas de la fila 0, luego todas las de la fila 1, y así sucesivamente. Recorrer por columnas hace lo contrario.

Por filas

for (int i = 0; i < filas; i++)
    for (int j = 0; j < columnas; j++)
        procesar(m[i][j]);

Por columnas

for j in range(columnas):
    for i in range(filas):
        procesar(m[i][j])

El orden de los ciclos no cambia el resultado, pero sí el orden en que se visitan las casillas.

Qué significa guardar una matriz por filas

Guardar por filas (row-major order) significa que todos los valores de la fila 0 quedan seguidos en memoria, después todos los de la fila 1, y así con cada fila siguiente.

Qué es un arreglo de arreglos, en Java

En Java, una matriz no es un bloque 2D real: es un arreglo cuyos elementos son referencias a otros arreglos, las filas, cada una un objeto independiente en el heap.

Arreglos irregulares (jagged)

Un arreglo irregular (jagged) aprovecha justo eso: cada fila declara su propio tamaño.

int[][] triangular = new int[4][];
for (int i = 0; i < 4; i++) {
    triangular[i] = new int[i + 1];
}

El NullPointerException que sorprende

Filas listas de una vez

int[][] m = new int[3][2];
m[0][0] = 5;   // funciona

Filas en null

int[][] m = new int[3][];
m[0][0] = 5;
// NullPointerException:
// la fila 0 todavia no existe

new int[3][2] crea las tres filas en ceros de inmediato. new int[3][] solo crea el arreglo exterior: cada fila vale null (ninguna referencia todavía) hasta que se asigna explícitamente.

m[0] = new int[2];  // ahora si
m[0][0] = 5;

Qué hace clone() en un arreglo de arreglos

clone() crea un arreglo nuevo copiando, uno a uno, los valores del arreglo original. Si esos valores son referencias, como las filas de una matriz, copia las referencias, no los objetos a los que apuntan.

Copia superficial contra copia profunda

Copia superficial

Copia solo las referencias externas. Las filas siguen siendo los mismos objetos compartidos.

Copia profunda

Copia también el contenido de cada fila, creando objetos nuevos e independientes.

int[][] original = {{1, 2}, {3, 4}};
int[][] copia = original.clone();
copia[0][0] = 999;
System.out.println(original[0][0]); // imprime 999: copia superficial

Para una copia real hay que clonar cada fila:

int[][] profunda = new int[original.length][];
for (int i = 0; i < original.length; i++) {
    profunda[i] = original[i].clone();
}

Python: lista de listas

filas, columnas = 3, 4
matriz = [[0] * columnas for _ in range(filas)]

Python no tiene un arreglo bidimensional nativo. El módulo array es de una sola dimensión; su propia documentación remite a NumPy para trabajo numérico serio con matrices.

Qué hace el operador * sobre una lista

[valor] * n crea una lista repitiendo n veces la misma referencia a valor, no n copias independientes. Si valor es a su vez una lista mutable, las n posiciones apuntan al mismo objeto.

El bug clásico de multiplicar listas

mal = [[0] * 2] * 3
mal[0][0] = 5      # las tres filas cambian: [[5, 0], [5, 0], [5, 0]]

bien = [[0] * 2 for _ in range(3)]
bien[0][0] = 5     # solo la fila 0 cambia

Un tablero del juego de la vida construido como [[False] * ancho] * alto sufre el mismo bug: marcar una celda viva enciende toda una columna en todas las filas a la vez.

Bloque 3. Pilas y colas con vectores

Bloque 3

Dos contratos clásicos, resueltos con el mismo arreglo que crece.

Qué es una pila

Una pila es una estructura donde el último elemento en entrar es el primero en salir: LIFO, last in, first out.

Analogía: una pila de platos. Solo puedes tomar el de encima, y solo puedes dejar uno nuevo encima de todos los demás.

La operación apilar

Apilar agrega un elemento nuevo justo encima del último. En un arreglo, eso significa escribir en la primera casilla libre y avanzar el contador de tamaño.

La operación desapilar

Desapilar quita y devuelve el elemento de arriba. En un arreglo, eso es leer la última casilla ocupada y retroceder el contador de tamaño.

Las operaciones cima y estaVacia

cima()

Devuelve el elemento de arriba sin quitarlo de la pila.

estaVacia()

Responde si la pila no tiene ningún elemento ocupado.

Diseño de la clase Pila

datos

Object[], el arreglo que guarda los elementos.

tamaño

int, cuántos elementos hay ocupados de verdad.

Pila completa en Java (1 de 2)

public class Pila {
    private Object[] datos;
    private int tamano;
    public Pila() { datos = new Object[10]; tamano = 0; }
    public void apilar(Object elemento) {
        if (tamano == datos.length) redimensionar();
        datos[tamano] = elemento;
        tamano++;
    }
    public Object desapilar() {
        if (estaVacia()) throw new IllegalStateException("la pila esta vacia");
        tamano--;
        Object e = datos[tamano];
        datos[tamano] = null;
        return e;
    }

Pila completa en Java (2 de 2)

Continúa la misma clase Pila de la diapositiva anterior.

Pila completa en Python (1 de 2)

class Pila:
    def __init__(self):
        self._datos = [None] * 10
        self._tamano = 0
    def apilar(self, elemento):
        if self._tamano == len(self._datos):
            self._redimensionar()
        self._datos[self._tamano] = elemento
        self._tamano += 1
    def desapilar(self):
        if self.esta_vacia():
            raise IndexError("la pila esta vacia")
        self._tamano -= 1
        e = self._datos[self._tamano]
        self._datos[self._tamano] = None
        return e

Referencias obsoletas: por qué desapilar pone null

public Object desapilar() {
    tamano--;
    Object e = datos[tamano];
    datos[tamano] = null;   // sin esto, la referencia queda viva
    return e;
}

Sin ese null, el recolector de basura no puede liberar el objeto aunque ya lo hayas olvidado lógicamente. Effective Java de Joshua Bloch usa exactamente una pila con arreglo como ejemplo de este problema, al que llama referencias obsoletas.

Qué es una cola

Una cola es una estructura donde el primer elemento en entrar es el primero en salir: FIFO, first in, first out.

Analogía: la fila de un banco. Quien llega primero, se atiende primero; los nuevos se suman al final de la fila.

La operación encolar

Encolar agrega un elemento por el extremo llamado fin, sin tocar el resto de la fila.

La operación desencolar

Desencolar quita y devuelve el elemento del extremo llamado frente, el más antiguo de la fila.

Por qué la cola ingenua falla

cola = []
cola.append(x)          # entra al final, esto si es barato
primero = cola.pop(0)   # sale del inicio: O(n) cada vez

Quitar siempre de la posición 0 desplaza todo lo demás. La solución no es mover los elementos, es mover los índices.

Qué es un arreglo circular

Un arreglo circular es un arreglo normal donde, al llegar a la última casilla, el siguiente índice vuelve a la posición 0 en vez de salirse del arreglo.

Analogía: una pista de atletismo. Un corredor que llega a la meta no se detiene contra una pared: sigue corriendo y vuelve al punto de partida, dando otra vuelta sobre la misma pista.

El arreglo circular en mecánica

El operador módulo (%) devuelve el resto de una división. Por eso al llegar a la posición 6 en un arreglo de capacidad 6, 6 % 6 = 0, y el índice vuelve al inicio.

La ambigüedad de frente == fin

Con solo dos índices, una cola vacía y una cola llena pueden verse exactamente igual: frente == fin en ambos casos. Hace falta un tercer dato para distinguirlas.

Solución A: contador de tamaño

Guardar cuántos elementos hay, además de frente. Es la que usa esta implementación.

Solución B: sacrificar un espacio

Nunca llenar la última casilla. La documentación de buffers circulares del kernel de Linux la usa, y de paso permite cambiar el módulo por una máscara AND si la capacidad es potencia de 2.

Cola completa en Java (1 de 2)

public class Cola {
    private Object[] datos;
    private int frente;
    private int tamano;
    public Cola() { datos = new Object[10]; frente = 0; tamano = 0; }
    public void encolar(Object elemento) {
        if (tamano == datos.length) redimensionar();
        int posicion = (frente + tamano) % datos.length;
        datos[posicion] = elemento;
        tamano++;
    }
    public Object frente() {
        if (estaVacia()) throw new IllegalStateException("la cola esta vacia");
        return datos[frente];
    }
    public boolean estaVacia() { return tamano == 0; }

Cola completa en Java (2 de 2)

Continúa la misma clase Cola de la diapositiva anterior.

    public Object desencolar() {
        if (estaVacia()) throw new IllegalStateException("la cola esta vacia");
        Object e = datos[frente];
        datos[frente] = null;
        frente = (frente + 1) % datos.length;
        tamano--;
        return e;
    }
    private void redimensionar() {
        Object[] nuevo = new Object[datos.length * 2];
        for (int i = 0; i < tamano; i++) {
            nuevo[i] = datos[(frente + i) % datos.length];
        }
        datos = nuevo;
        frente = 0;
    }
}

Cola completa en Python (1 de 2)

class Cola:
    def __init__(self):
        self._datos = [None] * 10
        self._frente = 0
        self._tamano = 0
    def encolar(self, elemento):
        if self._tamano == len(self._datos):
            self._redimensionar()
        posicion = (self._frente + self._tamano) % len(self._datos)
        self._datos[posicion] = elemento
        self._tamano += 1

Lo que conecta toda la unidad

  • La notación O compara algoritmos por cómo escalan, no por velocidad de máquina
  • Un arreglo calcula la dirección de cada casilla: acceso O(1)
  • Insertar o eliminar en medio cuesta O(n) por el desplazamiento
  • Java reserva memoria fija; crecer significa copiar a un arreglo nuevo
  • Capacidad y tamaño son ideas distintas: una es espacio, la otra es uso real
  • Una matriz en Java es un arreglo de arreglos, filas independientes
  • [[0]*n]*m comparte una sola fila entre todas las referencias
  • Redimensionar siempre copia primero y escribe después
  • El costo de redimensionar, repartido entre todas las llamadas, es O(1) amortizado
  • El arreglo circular mueve índices con módulo, nunca elementos
  • Olvidar limpiar una referencia deja basura que el recolector no puede liberar

Estructuras fijas: el resumen en una idea

Un arreglo resuelve todo esto con aritmética sobre memoria contigua. El costo aparece exactamente cuando algo tiene que moverse o crecer, nunca antes.
