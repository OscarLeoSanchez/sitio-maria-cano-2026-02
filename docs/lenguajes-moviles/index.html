De qué se trata el curso

Programar para un teléfono no es programar para un computador con la pantalla más pequeña. El dispositivo tiene sensores, batería que se agota, conexión que se cae y un usuario que lo usa de pie y con una sola mano. Este curso te enseña a construir aplicaciones que tienen en cuenta todo eso.

Empezamos por el dispositivo: de qué está hecho por dentro y qué te ofrece que un escritorio no tiene. Seguimos con el entorno de trabajo, que en desarrollo móvil pesa más que en cualquier otra plataforma: línea de comandos, control de versiones con Git y las herramientas de construcción y depuración. Cerramos con desarrollo web multiplataforma, donde una sola base de código se instala y se comporta como aplicación en cualquier teléfono.

Viene después de Lenguajes de programación para la web y se apoya en eso: aquí llevas lo que ya sabes de la web al dispositivo móvil.

Unidades de aprendizaje

Unidad 1. Tecnologías en desarrollo de aplicaciones para dispositivos móviles

Resultado de aprendizaje. Identificas las bases de las tecnologías utilizadas en las aplicaciones que se desarrollan en dispositivos móviles.

Temas:

  • Dispositivos móviles y sus componentes físicos. Qué hay dentro del dispositivo y qué límites le impone a tu aplicación. La memoria, el almacenamiento y la batería no son infinitos, y el diseño tiene que contar con eso desde el principio.
  • Procesadores. La arquitectura del móvil y por qué se optimiza para consumo antes que para potencia bruta. Explica buena parte de las decisiones del sistema operativo sobre tu aplicación.
  • Transmisores de información. Las radios del dispositivo: red celular, Wi-Fi, Bluetooth y NFC. Cada una con su alcance, su velocidad y su costo en batería.
  • Sensores. Acelerómetro, giroscopio, GPS, cámara y proximidad. Lo que de verdad distingue una aplicación móvil: la posibilidad de reaccionar al mundo físico.
  • Componentes lógicos. El sistema operativo, el modelo de permisos y el ciclo de vida de una aplicación. Tu programa no controla cuándo se detiene: eso lo decide el sistema.
  • Categorización, modos de operación e interacciones. Aplicación nativa, web e híbrida. Cómo se comporta cada una con y sin conexión, y cómo cambia la interacción cuando la entrada es táctil.
  • Seguridad. Dónde se guardan los datos en el dispositivo, qué queda expuesto y qué pide el usuario cuando concede un permiso.

Unidad 2. Herramientas de trabajo en desarrollo de aplicaciones para dispositivos móviles

Resultado de aprendizaje. Identificas los entornos y herramientas de trabajo para el desarrollo de aplicaciones en dispositivos móviles.

Temas:

  • Entorno y herramientas de desarrollo. El conjunto mínimo para trabajar: editor, kit de desarrollo, emulador y dispositivo físico. Cómo se monta y cómo se verifica que quedó bien montado.
  • Línea de comandos. La interfaz con la que se instalan dependencias, se construye el proyecto y se depura contra un dispositivo. En móvil no es opcional.
  • Repositorio de software con Git. Control de versiones local: confirmaciones, ramas y reversión. La red de seguridad que te permite equivocarte sin perder el trabajo.
  • Servicio web de control de versiones. El repositorio remoto y el trabajo en equipo: publicar, traer cambios y resolver conflictos.
  • Herramientas avanzadas de desarrollo. Depuración, inspección del dispositivo, medición de rendimiento y empaquetado para distribución.
  • La web desde el prisma del desarrollo móvil. Qué cambia en HTML, CSS y JavaScript cuando el destino es una pantalla táctil con conexión intermitente.
  • Programación en el desarrollo de aplicaciones móviles. Componentes, estado y eventos: la forma de organizar el código que comparten las herramientas actuales.

Unidad 3. Desarrollo web multiplataforma orientado a dispositivos móviles

Resultado de aprendizaje. Identificas el desarrollo web multiplataforma orientado a los dispositivos móviles.

Temas:

  • Desarrollo web multiplataforma. Una sola base de código para varios sistemas operativos. Qué se gana en tiempo y en mantenimiento, y qué se pierde frente a una aplicación nativa.
  • Progressive Web Apps. La aplicación web que se instala, guarda datos y funciona sin conexión. Qué hace falta para que un sitio se comporte como aplicación.
  • Frameworks de desarrollo web. Qué resuelve un framework que no resolverías a mano, y con qué criterios se elige uno para un proyecto móvil.
  • Framework multiplataforma Flutter. Un solo código en Dart que compila a interfaz nativa en Android, iOS y web. El framework con el que el curso construye la Unidad 3.
  • Biblioteca de desarrollo React. Componentes y estado con un enfoque mínimo, donde lo demás se arma eligiendo piezas. Se usa como punto de comparación frente a Flutter, sin ser la base de las entregas del curso.
