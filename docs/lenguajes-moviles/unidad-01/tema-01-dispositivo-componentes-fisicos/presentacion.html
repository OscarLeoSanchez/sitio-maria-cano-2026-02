Dos consecuencias para todo el semestre

La memoria es fija

No puedes pedirle al usuario que agregue más. El aparato que tiene es el que tiene, y ahí corre tu aplicación.

La memoria es compartida

El sistema, tu aplicación y todas las demás sacan de la misma bolsa. El sistema tiene que poder recuperarle memoria a alguien, y ese alguien puede ser tu aplicación mientras el usuario mira otra cosa.

Quién decide cuándo corre tu código

Android lo dice así

WorkManager agrupa tareas y la restricción RequiresCharging impide ejecutar trabajo salvo que el equipo esté cargando. El sistema limita a propósito la ubicación en segundo plano.

Apple lo dice así

Minimizar entrada y salida, agrupar transacciones de red y usar clases de calidad de servicio para priorizar. La red es uno de los mayores consumos de energía.

Tu código declara condiciones y el sistema escoge el momento. Dos empresas con sistemas distintos publican la misma recomendación.

Android, Optimizar para la batería del dispositivo. Apple, Energy Efficiency Guide for iOS Apps.

Los tres niveles de permiso de Android

Normal

Lo concede el sistema solo, sin preguntar. El riesgo para el usuario es bajo.

Peligroso

Exige consentimiento explícito del usuario. Cámara, ubicación, contactos.

De firma

Reservado a aplicaciones firmadas por el mismo desarrollador.

Una nativa concede permisos una vez y se queda instalada con su identidad. Un sitio que se muda de dominio empieza de cero.

La letra pequeña de iOS

Si tu producto depende de notificaciones, ese paso extra del usuario deja de ser un detalle y se vuelve parte del diseño. En Colombia importa: parte del grupo usa iPhone.

WebKit, Web Push for Web Apps on iOS and iPadOS.

Tres confusiones que conviene resolver hoy

Sitio responsivo no es aplicación

Para que se comporte como aplicación hacen falta manifiesto, HTTPS y service worker. Sin eso es un sitio que se ve bien en el teléfono.

Responsivo no es adaptable

Responsivo reorganiza un mismo layout con media queries. Adaptable sirve variantes distintas de interfaz según el dispositivo o la capacidad detectada.

La PWA no reemplaza a la nativa

En iOS el push exige instalación previa. El acceso a sensores desde la web tiene soporte desigual entre navegadores.

Angular se presenta como el framework para construir aplicaciones web modernas. Lo mantiene un equipo de Google, está basado en TypeScript y su arquitectura es de componentes.
