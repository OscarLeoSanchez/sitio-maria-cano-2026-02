Estructuras dinámicas, Listas, pilas y colas

El reproductor de música: listas, pilas y colas

Preguntas para construirlo, medirlo y decidir

Una aplicación de música guarda listas de reproducción, deja agregar y quitar canciones, saltar adelante y atrás, repetir y recordar lo que ya sonó. Cada una de esas funciones es una pregunta sobre cómo se guardan los datos. En esta actividad usted va a construir el reproductor, pero lo que lo guía es una lista de preguntas: si las responde en orden, las listas enlazadas, las pilas y las colas aparecen solas como la respuesta que necesita.

i

¿Quiere ver cómo se mueve cada idea antes de empezar, o cuando una pregunta se le atraviese? Abra la explicación interactiva: cada diapositiva parte de una pregunta de esta actividad.

Propósito

Al terminar usted será capaz de:

  • Explicar por qué una canción nueva puede entrar en un reproductor sin mover las demás, y qué referencias lo hacen posible.
  • Construir una lista doblemente enlazada con cursor y modo repetir, y hacer que pase las mismas pruebas que una lista respaldada por un arreglo.
  • Predecir el costo de cada operación y de la memoria antes de medir, y explicar por qué el mismo O grande no da el mismo tiempo.
  • Distinguir una pila de una cola por el orden en que sale lo que entró, y construir ambas sobre su propia lista.
  • Decidir con cifras propias entre un arreglo y una lista enlazada para escenarios distintos, y reconocer cuándo ninguna de las dos basta.

Cómo se trabaja

  • Trabajo en parejas. Los dos integrantes deben poder explicar cualquier parte de la hoja y del código.
  • No se usan asistentes de inteligencia artificial durante la actividad.
  • Fuentes permitidas: las guías de los Temas 1 y 2 de la Unidad 3, la documentación oficial de Python y el Javadoc de Java. Todo dato que tome de una fuente se cita en la hoja con el nombre de la fuente.
  • Las respuestas de predicción y los dibujos van a mano, en una hoja con los nombres de los dos integrantes, en el orden de las preguntas y sobre la marcha. No se pasa en limpio al final.
  • Cada número de la hoja lleva la operación de la que salió, y cada O(...) lleva la explicación de qué se mueve, qué se recorre o qué referencias cambian.
  • La Parte 1 corresponde a la primera sesión (Tema 1, listas enlazadas) y la Parte 2 a la segunda (Tema 2, pilas y colas con listas). La Parte 2 usa la lista que construya en la Parte 1.

El problema

Un reproductor de música debe administrar listas de hasta un millón de canciones. El usuario toca estos botones, y cada uno es una operación sobre la estructura que guarda las canciones:

La lista dice qué canciones hay y cuál suena. La cola guarda lo que el usuario pidió que suene después. El historial guarda lo que ya sonó para poder volver.

La estructura de partida es un arreglo, y por eso el código base ya trae la lista de reproducción hecha con un list de Python (ListaConArreglo). Su trabajo es construir la misma lista con nodos y referencias, que cumpla exactamente el mismo contrato, y averiguar con evidencia propia cuándo conviene una y cuándo la otra.

# ----------------------------------------------------------------------
# 2. La lista de reproducción con arreglo
#    Es el contrato que usted debe cumplir con nodos. Léalo con calma:
#    cada comentario dice qué debe pasar, incluso en los casos de borde.
# ----------------------------------------------------------------------

class ListaConArreglo:
    """Lista de reproducción con un cursor (la canción que suena).

    Contrato:
      - actual() devuelve la canción que suena, o None si la lista está vacía.
      - Al agregar la primera canción, el cursor queda sobre ella. Después, agregar
        no mueve el cursor: la canción que suena sigue sonando.
      - siguiente() y anterior() mueven el cursor y devuelven la canción nueva. Si no hay
        a dónde moverse devuelven None y el cursor no se mueve. Con repetir en True,
        pasar del último salta al primero y retroceder del primero salta al último.
      - ir_a(k) mueve el cursor a la posición k (desde 0) y devuelve la canción. Si k
        está fuera de rango lanza IndexError.
      - quitar_actual() y quitar_en(k) devuelven la canción quitada. Si quitan la que
        suena, el cursor pasa a la siguiente; si era la última, pasa a la anterior.
        Si quitan otra canción, el cursor sigue sobre la misma. Con la lista vacía o k
        fuera de rango lanzan IndexError.
      - a_lista() devuelve las canciones en orden, una sola vez cada una, aunque
        repetir esté en True.
    """

    def __init__(self):
        self._datos = []
        self._pos = -1          # posición del cursor; -1 si no hay canciones
        self._repetir = False

    def __len__(self):
        return len(self._datos)

    @property
    def repetir(self):
        return self._repetir

    @repetir.setter
    def repetir(self, valor):
        self._repetir = bool(valor)

    def actual(self):
        return self._datos[self._pos] if self._datos else None

    def agregar_al_inicio(self, cancion):
        self._datos.insert(0, cancion)
        self._pos = 0 if self._pos == -1 else self._pos + 1

    def agregar_al_final(self, cancion):
        self._datos.append(cancion)
        if self._pos == -1:
            self._pos = 0

    def agregar_despues_de_actual(self, cancion):
        if self._pos == -1:
            self.agregar_al_final(cancion)
        else:
            self._datos.insert(self._pos + 1, cancion)

    def siguiente(self):
        if not self._datos:
            return None
        if self._pos + 1 < len(self._datos):
            self._pos += 1
        elif self._repetir:
            self._pos = 0
        else:
            return None
        return self._datos[self._pos]

    def anterior(self):
        if not self._datos:
            return None
        if self._pos > 0:
            self._pos -= 1
        elif self._repetir:
            self._pos = len(self._datos) - 1
        else:
            return None
        return self._datos[self._pos]

    def ir_a(self, k):
        if not 0 <= k < len(self._datos):
            raise IndexError("posicion fuera de rango")
        self._pos = k
        return self._datos[k]

    def quitar_actual(self):
        if not self._datos:
            raise IndexError("la lista esta vacia")
        return self.quitar_en(self._pos)

    def quitar_en(self, k):
        if not 0 <= k < len(self._datos):
            raise IndexError("posicion fuera de rango")
        cancion = self._datos.pop(k)
        if k < self._pos:
            self._pos -= 1
        elif k == self._pos and self._pos >= len(self._datos):
            self._pos = len(self._datos) - 1
        return cancion

    def a_lista(self):
        return list(self._datos)

class ColaConArreglo:
    """Cola respaldada por un list de Python: desencolar quita el elemento 0."""

    def __init__(self):
        self._datos = []

    def encolar(self, elemento):
        self._datos.append(elemento)

    def desencolar(self):
        if not self._datos:
            raise IndexError("la cola esta vacia")
        return self._datos.pop(0)

    def frente(self):
        if not self._datos:
            raise IndexError("la cola esta vacia")
        return self._datos[0]

    def esta_vacia(self):
        return not self._datos

    def tamaño(self):
        return len(self._datos)


class ColaEnlazada:
    """Cola con nodos: entra por el último, sale por la cabeza."""

    def __init__(self):
        self._cabeza = None
        self._ultimo = None
        self._tamaño = 0

    def encolar(self, elemento):
        nuevo = NodoDoble(elemento)
        if self._ultimo is None:
            self._cabeza = nuevo
            self._ultimo = nuevo
        else:
            self._ultimo.siguiente = nuevo
            self._ultimo = nuevo
        self._tamaño += 1

    def desencolar(self):
        if self._cabeza is None:
            raise IndexError("la cola esta vacia")
        eliminado = self._cabeza
        self._cabeza = eliminado.siguiente
        if self._cabeza is None:
            self._ultimo = None
        eliminado.siguiente = None
        self._tamaño -= 1
        return eliminado.dato

    def frente(self):
        if self._cabeza is None:
            raise IndexError("la cola esta vacia")
        return self._cabeza.dato

    def esta_vacia(self):
        return self._cabeza is None

    def tamaño(self):
        return self._tamaño


class ColaEnlazadaConError(ColaEnlazada):
    """La misma cola, con una línea menos en desencolar. No la arregle: investíguela."""

    def desencolar(self):
        if self._cabeza is None:
            raise IndexError("la cola esta vacia")
        eliminado = self._cabeza
        self._cabeza = eliminado.siguiente
        eliminado.siguiente = None
        self._tamaño -= 1
        return eliminado.dato


class PilaEnlazada:
    """Pila con nodos: todo ocurre sobre la cabeza."""

    def __init__(self):
        self._cabeza = None
        self._tamaño = 0

    def apilar(self, elemento):
        nuevo = NodoDoble(elemento)
        nuevo.siguiente = self._cabeza
        self._cabeza = nuevo
        self._tamaño += 1

    def desapilar(self):
        if self._cabeza is None:
            raise IndexError("la pila esta vacia")
        eliminado = self._cabeza
        self._cabeza = eliminado.siguiente
        eliminado.siguiente = None
        self._tamaño -= 1
        return eliminado.dato

    def cima(self):
        if self._cabeza is None:
            raise IndexError("la pila esta vacia")
        return self._cabeza.dato

    def esta_vacia(self):
        return self._cabeza is None

    def tamaño(self):
        return self._tamaño

# 4. El reproductor completo
#    Junta la lista (la que suena), la cola "A continuación" y el historial.
# ----------------------------------------------------------------------

class Reproductor:
    def __init__(self, lista, a_continuacion, historial):
        self.lista = lista
        self.a_continuacion = a_continuacion
        self.historial = historial
        self.sonando = lista.actual()

    def agregar_a_la_cola(self, cancion):
        """Botón "Agregar a la cola": la canción sonará después de las que ya esperan."""
        self.a_continuacion.encolar(cancion)

    def reproducir_a_continuacion(self, cancion):
        """Botón "Reproducir a continuación": la canción sonará antes que las que esperan."""
        self.a_continuacion.reproducir_a_continuacion(cancion)

    def siguiente(self):
        """Botón "Siguiente": guarda la que sonaba y pasa a la cola o, si está vacía, a la lista."""
        if self.sonando is not None:
            self.historial.apilar(self.sonando)
        if not self.a_continuacion.esta_vacia():
            self.sonando = self.a_continuacion.desencolar()
        else:
            self.sonando = self.lista.siguiente()
        return self.sonando

    def volver(self):
        """Botón "Volver": recupera la última del historial. Si no hay, sigue la misma."""
        if not self.historial.esta_vacia():
            self.sonando = self.historial.desapilar()
        return self.sonando

def llena(clase, n):
    """Una lista de reproducción con n canciones (enteros) y el cursor en la mitad."""
    lista = clase()
    for i in range(n):
        lista.agregar_al_final(i)
    lista.ir_a(n // 2)
    return lista


def fabrica_lista(clase):
    return lambda n: llena(clase, n)


def _formato(segundos):
    if segundos < 1e-6:
        return f"{segundos * 1e9:9.1f} ns"
    if segundos < 1e-3:
        return f"{segundos * 1e6:9.2f} us"
    if segundos < 1:
        return f"{segundos * 1e3:9.2f} ms"
    return f"{segundos:9.2f}  s"


def comparar(nombre, operacion, fabricas, repeticiones=100, tamanos=TAMANOS):
    """Mide una operación sobre cada tamaño y cada estructura.

    fabricas es un diccionario {etiqueta: funcion(n) que devuelve la estructura llena}.
    operacion(estructura, n) se repite `repeticiones` veces y se muestra el promedio.
    """
    print(f"== {nombre}  ({repeticiones} repeticiones por tamaño)")
    for n in tamanos:
        columnas = []
        for etiqueta, fabrica in fabricas.items():
            estructura = fabrica(n)
            inicio = time.perf_counter()
            for _ in range(repeticiones):
                operacion(estructura, n)
            promedio = (time.perf_counter() - inicio) / repeticiones
            columnas.append(f"{etiqueta} {_formato(promedio)}")
        print(f"   n={n:>9,}   " + "   |   ".join(columnas))
    print()


def medir_memoria(fabrica, n):
    """Bytes que ocupa la estructura con n canciones, medidos con tracemalloc.

    Incluye los enteros que guarda. Mídala en una ejecución aparte de los tiempos.
    """
    tracemalloc.start()
    estructura = fabrica(n)
    actual, _ = tracemalloc.get_traced_memory()
    tracemalloc.stop()
    del estructura
    return actual

class CicloInfinito(Exception):
    pass


def _con_limite(funcion, limite=300_000):
    """Ejecuta funcion() y corta con CicloInfinito si hace demasiados pasos."""
    cuenta = [0]

    def traza(frame, evento, arg):
        cuenta[0] += 1
        if cuenta[0] > limite:
            raise CicloInfinito()
        return traza

    sys.settrace(traza)
    try:
        return funcion()
    finally:
        sys.settrace(None)


def _igual(obtenido, esperado, que):
    assert obtenido == esperado, f"{que}: esperaba {esperado!r} y obtuvo {obtenido!r}"


def _lanza(tipo, funcion, que):
    try:
        funcion()
    except tipo:
        return
    except Exception as e:
        raise AssertionError(f"{que}: esperaba {tipo.__name__} y obtuvo {type(e).__name__}")
    raise AssertionError(f"{que}: esperaba {tipo.__name__} y no lanzó nada")


def _lista(clase, *canciones):
    lista = clase()
    for c in canciones:
        lista.agregar_al_final(c)
    return lista


def _p_vacia(C):
    l = C()
    _igual(len(l), 0, "len de la lista vacía")
    _igual(l.actual(), None, "actual() vacía")
    _igual(l.siguiente(), None, "siguiente() vacía")
    _igual(l.anterior(), None, "anterior() vacía")
    _igual(l.a_lista(), [], "a_lista() vacía")
    _lanza(IndexError, l.quitar_actual, "quitar_actual() vacía")
    _lanza(IndexError, lambda: l.ir_a(0), "ir_a(0) vacía")

def _p_diferencial(C):
    rnd = random.Random(7)
    ref, est = ListaConArreglo(), C()
    contador = 0
    for paso in range(1500):
        n = len(ref)
        opciones = ["inicio", "final", "despues", "sig", "ant", "ir_a",
                    "quitar_actual", "quitar_en", "repetir"]
        pesos = [3, 3, 3, 3, 3, 2, 2, 2, 1] if n >= 4 else [4, 4, 4, 1, 1, 1, 0, 0, 1]
        op = rnd.choices(opciones, pesos)[0]
        k = rnd.randint(-1, n)
        contador += 1
        dato = f"c{contador}"

        def ejecutar(lista):
            if op == "inicio":
                return lista.agregar_al_inicio(dato)
            if op == "final":
                return lista.agregar_al_final(dato)
            if op == "despues":
                return lista.agregar_despues_de_actual(dato)
            if op == "sig":
                return lista.siguiente()
            if op == "ant":
                return lista.anterior()
            if op == "ir_a":
                return lista.ir_a(k)
            if op == "quitar_actual":
                return lista.quitar_actual()
            if op == "quitar_en":
                return lista.quitar_en(k)
            lista.repetir = not lista.repetir

        def intentar(lista):
            try:
                return ("ok", _con_limite(lambda: ejecutar(lista)))
            except IndexError:
                return ("IndexError", None)

        esperado, obtenido = intentar(ref), intentar(est)
        donde = f"paso {paso}, {op}" + (f"({k})" if op in ("ir_a", "quitar_en") else "")
        _igual(obtenido, esperado, f"resultado de la operación ({donde})")
        _igual(_con_limite(est.a_lista), ref.a_lista(), f"a_lista tras la operación ({donde})")
        _igual(est.actual(), ref.actual(), f"actual tras la operación ({donde})")
        _igual(len(est), len(ref), f"len tras la operación ({donde})")

def _correr(pruebas, clase):
    fallas = 0
    for nombre, prueba in pruebas:
        try:
            _con_limite(lambda: prueba(clase), limite=3_000_000)
            print(f"OK        {nombre}")
        except NotImplementedError:
            fallas += 1
            print(f"PENDIENTE {nombre}")
        except CicloInfinito:
            fallas += 1
            print(f"FALLA     {nombre}: se quedó dando vueltas (¿un recorrido que no termina?)")
        except AssertionError as e:
            fallas += 1
            print(f"FALLA     {nombre}: {e}")
        except Exception as e:
            fallas += 1
            print(f"ERROR     {nombre}: {type(e).__name__}: {e}")
    print("Todo en orden." if fallas == 0 else f"{fallas} prueba(s) sin pasar.")
