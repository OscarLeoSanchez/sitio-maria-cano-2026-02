Filtros de imagen como operaciones entre matrices

Predecir, medir y decidir

Una fotografía en escala de grises es una matriz de números enteros, y casi todo lo que hace un programa de edición (desenfocar, afilar, detectar bordes, quitar ruido) es una operación entre esa matriz y otra mucho más pequeña. En esta actividad va a construir esas operaciones, pero lo más valioso es lo que hace alrededor: decir de antemano cuánto va a costar cada una, medirlo y explicar por qué su predicción acertó o falló.

El problema

De la imagen a la matriz

Una imagen en escala de grises es una matriz de enteros de 0 (negro) a 255 (blanco). En Python es una lista de listas: img[i][j] es el píxel de la fila i, columna j. El código base ya trae las funciones para leer una imagen, guardarla y mostrarla, y una imagen de prueba que siempre es la misma: un degradado, un cuadrado claro, un círculo oscuro y un 3 % de píxeles sueltos blancos o negros (ruido).

Qué hace un filtro

Un filtro calcula una imagen nueva, píxel por píxel. Lo que cambia entre un filtro y otro es de dónde saca los datos para calcular cada píxel nuevo. Hay tres familias:

FiltroFamiliaPara qué sirve

Los núcleos ya están definidos en el código base como parejas (pesos, divisor), por ejemplo PROMEDIO_3, REALCE, SOBEL_X, SOBEL_Y y GAUSS_5. Use siempre división entera (//). Así una sola función sirve para todos: convolucion(img, *PROMEDIO_3).

Los bordes

Cerca de la orilla, la ventana se sale de la imagen. En esta actividad todos los filtros de vecindad siguen la misma regla: el resultado tiene el mismo tamaño que la imagen y los r = k // 2 píxeles más externos se copian de la original. La excepción es Sobel, cuya franja queda en 0 (piense por qué copiarla no tendría sentido).

def negativo(img):
    alto, ancho = len(img), len(img[0])
    resultado = [[0] * ancho for _ in range(alto)]   # filas independientes
    for i in range(alto):
        for j in range(ancho):
            resultado[i][j] = 255 - img[i][j]
    return resultado

C, Memoria

Una matriz de 512 × 512 en Python es una lista de 512 filas, y cada fila es una lista de 512 referencias. En una máquina de 64 bits una referencia ocupa 8 bytes y una lista guarda además unos 56 bytes de encabezado.

  1. ¿Cuántos bytes ocupa la estructura (listas y referencias) de una matriz de 512 × 512? Exprese el resultado también en KiB.
  2. Cada celda apunta a un objeto entero. Python reutiliza un único objeto para cada entero entre −5 y 256, pero crea objetos nuevos (de 28 a 32 bytes cada uno) para los demás. ¿En cuál de los siete filtros espera que el resultado contenga enteros fuera de ese rango? ¿Qué le pasaría a la memoria que queda ocupada al terminar?

import random
import sys

from PIL import Image


# ----------------------------------------------------------------------
# 1. Imagen <-> matriz
#    Una imagen en escala de grises es una matriz de enteros 0..255:
#    0 = negro, 255 = blanco. Aquí la matriz es una lista de listas:
#    img[i][j] es el píxel de la fila i, columna j.
# ----------------------------------------------------------------------

def cargar_imagen(ruta, lado=None):
    """Lee un archivo de imagen y lo devuelve como matriz (lista de listas).

    La convierte a escala de grises ('L'). Si se indica `lado`, la
    redimensiona a un cuadrado lado x lado.
    """
    imagen = Image.open(ruta).convert("L")
    if lado is not None:
        imagen = imagen.resize((lado, lado))
    ancho, alto = imagen.size
    datos = imagen.tobytes()  # ancho*alto bytes seguidos, fila tras fila
    return [list(datos[i * ancho:(i + 1) * ancho]) for i in range(alto)]


def guardar_imagen(matriz, ruta):
    """Convierte una matriz en imagen y la guarda en `ruta` (por ejemplo 'salida.png').

    Los valores fuera de 0..255 se recortan: lo menor que 0 queda en 0 y
    lo mayor que 255 queda en 255.
    """
    alto, ancho = len(matriz), len(matriz[0])
    datos = bytearray()
    for fila in matriz:
        for valor in fila:
            datos.append(0 if valor < 0 else 255 if valor > 255 else int(valor))
    Image.frombytes("L", (ancho, alto), bytes(datos)).save(ruta)


def mostrar(matriz, escala=1):
    """Muestra una matriz como imagen.

    En Google Colab o Jupyter la imagen aparece debajo de la celda; en un editor
    se abre con el visor del sistema. `escala` agranda la imagen (útil si es pequeña).
    """
    alto, ancho = len(matriz), len(matriz[0])
    datos = bytes(0 if v < 0 else 255 if v > 255 else int(v) for fila in matriz for v in fila)
    imagen = Image.frombytes("L", (ancho, alto), datos)
    if escala != 1:
        imagen = imagen.resize((ancho * escala, alto * escala), Image.NEAREST)
    try:
        get_ipython()                       # solo existe dentro de Colab / Jupyter
    except NameError:
        imagen.show()
        return
    from IPython.display import display
    display(imagen)


def crear_imagen_prueba(lado, semilla=7):
    """Genera una imagen sintética lado x lado (siempre la misma para un lado dado).

    Trae un degradado suave, un cuadrado claro, un círculo oscuro y un 3 % de
    ruido "sal y pimienta" (píxeles sueltos en 0 o 255). Sirve para que cada
    filtro deje un efecto visible y para medir sin depender de una foto.
    """
    azar = random.Random(semilla)
    imagen = [[0] * lado for _ in range(lado)]     # filas independientes
    for i in range(lado):
        for j in range(lado):
            valor = (i + j) * 120 // (2 * lado) + 40
            if lado // 4 <= i < lado // 2 and lado // 4 <= j < lado // 2:
                valor = 230
            dx, dy = j - 3 * lado // 4, i - 3 * lado // 4
            if dx * dx + dy * dy < (lado // 6) ** 2:
                valor = 20
            if azar.random() < 0.03:
                valor = 0 if azar.random() < 0.5 else 255
            imagen[i][j] = valor
    return imagen


def crear_muestra(ruta="muestra.png"):
    """Guarda la imagen de prueba de 512 x 512 como archivo (la 'muestra.png' de la actividad)."""
    guardar_imagen(crear_imagen_prueba(512), ruta)
    return ruta

def medir_tiempo(funcion, *args, repeticiones=3):
    """Ejecuta funcion(*args) varias veces. Devuelve (resultado, mejor_tiempo_s).

    Se queda con el MEJOR tiempo: el equipo suele tener interrupciones
    ajenas al programa, y esas solo pueden sumar tiempo, nunca restarlo.
    """
    mejor = float("inf")
    resultado = None
    for _ in range(repeticiones):
        inicio = time.perf_counter()
        resultado = funcion(*args)
        fin = time.perf_counter()
        mejor = min(mejor, fin - inicio)
    return resultado, mejor


def medir_memoria(funcion, *args):
    """Ejecuta funcion(*args) una vez con tracemalloc activado.

    Devuelve (resultado, pico_bytes, retenido_bytes):
      pico_bytes     = el máximo de memoria adicional que la función tuvo
                       viva en algún instante de su ejecución.
      retenido_bytes = la memoria que sigue viva cuando la función termina
                       (básicamente, el resultado).

    OJO: tracemalloc vuelve el programa mucho más lento. Nunca mida tiempo
    y memoria en la misma ejecución.
    """
    tracemalloc.start()
    base, _ = tracemalloc.get_traced_memory()
    resultado = funcion(*args)
    actual, pico = tracemalloc.get_traced_memory()
    tracemalloc.stop()
    return resultado, pico - base, actual - base


def bytes_matriz(matriz, incluir_enteros=False):
    """Bytes que ocupa una lista de listas, según sys.getsizeof.

    Cuenta la lista externa y cada fila. Si incluir_enteros es True, suma
    además cada objeto entero distinto (por identidad) que contiene.
    """
    total = sys.getsizeof(matriz) + sum(sys.getsizeof(fila) for fila in matriz)
    if incluir_enteros:
        vistos = {}
        for fila in matriz:
            for valor in fila:
                vistos[id(valor)] = valor
        total += sum(sys.getsizeof(v) for v in vistos.values())
    return total

def medir(nombre, filtro, *args, lados=LADOS, repeticiones=3):
    """Mide un filtro sobre imágenes de prueba de cada lado y muestra una línea por tamaño.

    `filtro` es una función que recibe la imagen (matriz) como primer
    argumento y devuelve la matriz resultado: filtro(img, *args).
    """
    for lado in lados:
        imagen = crear_imagen_prueba(lado)
        _, tiempo = medir_tiempo(filtro, imagen, *args, repeticiones=repeticiones)
        _, pico, retenido = medir_memoria(filtro, imagen, *args)
        print(f"{nombre:28} lado={lado:>4} ({lado * lado:>7} px)  "
              f"{tiempo:9.4f} s   pico {pico / 1024:9.1f} KiB   "
              f"retenido {retenido / 1024:9.1f} KiB")
    print()

def son_iguales(a, b):
    """True si las dos matrices tienen las mismas dimensiones y los mismos valores."""
    return a == b


def diferencia_maxima(a, b):
    """Mayor diferencia absoluta entre celdas correspondientes de dos matrices del mismo tamaño."""
    if len(a) != len(b) or len(a[0]) != len(b[0]):
        raise ValueError("las matrices no tienen las mismas dimensiones")
    return max(abs(x - y) for fa, fb in zip(a, b) for x, y in zip(fa, fb))


def comprobar_contrato(filtro, *args, r=1, borde="copia"):
    """Revisa tres reglas que deben cumplir los filtros de vecindad de esta actividad:
      1) el resultado tiene las mismas dimensiones que la imagen,
      2) el filtro no modifica la imagen de entrada,
      3) la franja de borde (ancho r) queda como se pidió: borde="copia" exige que
         sea idéntica a la imagen original; borde="cero" exige que valga 0.

    Muestra OK o qué falla. NO comprueba que los valores del interior sean
    correctos: eso se verifica con sus cálculos a mano y con el parche de ejemplo.
    Ejemplo:  comprobar_contrato(convolucion, *PROMEDIO_5, r=2)
    """
    lado = 16
    img = crear_imagen_prueba(lado)
    copia = [fila[:] for fila in img]
    resultado = filtro(img, *args)
    problemas = []
    if len(resultado) != lado or any(len(fila) != lado for fila in resultado):
        problemas.append("las dimensiones del resultado no coinciden con las de la imagen")
    else:
        esperado = (lambda i, j: copia[i][j]) if borde == "copia" else (lambda i, j: 0)
        if any(resultado[i][j] != esperado(i, j)
               for i in range(lado) for j in range(lado)
               if i < r or i >= lado - r or j < r or j >= lado - r):
            problemas.append("la franja de borde no quedó como se pidió (" + borde + ")")
    if img != copia:
        problemas.append("el filtro modificó la imagen de entrada")
    if problemas:
        for p in problemas:
            print("FALLA:", p)
    else:
        print("OK: dimensiones, entrada intacta y borde correcto")
    return not problemas

def negativo(img):
    """Cada píxel del resultado depende SOLO del píxel que está en su misma posición."""
    alto, ancho = len(img), len(img[0])
    resultado = [[0] * ancho for _ in range(alto)]   # filas independientes
    for i in range(alto):
        for j in range(ancho):
            resultado[i][j] = 255 - img[i][j]
    return resultado

"""
extra_numpy.py  (reto de cierre, opcional)
La misma convolución, pero sobre un arreglo de NumPy en lugar de una lista de listas.
No hay que escribirla: se usa como "caja negra" para medir y comparar con la suya.

Requiere:  pip install numpy
"""

import numpy as np


def convolucion_numpy(img, kernel, divisor=1):
    """Igual que convolucion(img, kernel, divisor), pero devuelve un arreglo de NumPy.

    Convierte la lista de listas a un bloque contiguo (int32) y suma, para cada
    posición (da, db) del núcleo, la imagen desplazada multiplicada por su peso.
    """
    a = np.array(img, dtype=np.int32)
    k = len(kernel)
    r = k // 2
    alto, ancho = a.shape
    suma = np.zeros((alto - 2 * r, ancho - 2 * r), dtype=np.int32)
    for da in range(k):
        for db in range(k):
            suma += kernel[da][db] * a[da:alto - 2 * r + da, db:ancho - 2 * r + db]
    resultado = a.copy()
    resultado[r:alto - r, r:ancho - r] = suma // divisor
    return resultado
